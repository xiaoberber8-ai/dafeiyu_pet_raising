## 吃烤红薯-烫嘴哈气

**动作概述**

Q版蓝发鲸尾女仆原地站立，双手以魔法手势由虚到实凝出一只烤红薯和一只牛皮纸袋——红薯个头比她的脸还大一圈，表皮焦褐起皱，顶端裂开一道口子，冒着细细的白气，香气冲天。她捧起红薯，被烫得左右手来回倒腾、呼呼吹气，好不容易掰开，露出金黄流蜜的瓤，热气"腾"地冒上来糊了她一脸。她迫不及待咬下一大口，结果烫得舌头一缩、张嘴哈气、眼角泛泪，拎着红薯原地轻轻跺脚。缓过来后小口小口地吹着吃，最后满足地眯起眼，把牛皮纸袋和红薯皮一起凭空消散，恢复标准正面站立。全程原地站立，双脚锚定原点，红薯、纸袋、白气均在画幅安全区内。

**按秒分割画面**

0~2秒（变出红薯）：
标准正面站立。双手从身前以魔术般的动作，由半透明虚影渐次凝出一只烤红薯和一只牛皮纸袋。红薯焦褐表皮起皱、顶端裂口，冒出细白热气；纸袋敞口朝上，托在左手掌心。她双手捧起红薯，刚碰到就"哎哟"一下缩手，眉头一挑。
⚠️ 强调：红薯要明显"烫"——热气持续细微冒出；红薯表皮质感粗糙、有焦痕，不要画成光滑土豆；纸袋口朝上不遮挡脸。

2~4秒（烫手倒腾 → 掰开）：
女仆被烫得把红薯在左右手之间快速来回倒腾三次，每次都"呼、呼"地吹手指，眼睛瞪圆、嘴巴嘟起。随后她把红薯往中间一掰——"啪"地裂成两半，金黄流蜜的瓤露出来，一大团白气"腾"地升起，正好扑在她脸上，她眯起眼睛、鼻子皱起、被香气冲得表情发懵。
⚠️ 强调：掰开的动作要清晰，白气是向上"腾"起的一大团，但不得遮挡面部超过 0.5 秒；红薯断面要有金黄流心质感。

4~6.5秒（烫到哈气 → 跺脚）：
她迫不及待咬下一大口，刚入口表情就僵住——两眼猛地睁大，眼角泛起泪花，嘴巴"呼哈呼哈"地张着哈气，一只手在嘴边来回扇风，舌头微微伸出。随后她拎着红薯原地轻轻跺脚两下（脚尖原地点地，双脚不移动），尾巴紧张地卷起来。
⚠️ 强调：这是全片主笑点，核心是"贪吃被烫到"的委屈可爱，不是痛苦；跺脚必须是原地脚尖点地，**禁止身体前后左右平移**；舌头外伸幅度小而可爱。

6.5~8.5秒（吹着吃 → 满足）：

## 吃荔枝-剥壳弹飞

**动作概述**

Q版蓝发鲸尾女仆原地站立，双手以魔法手势由虚到实凝出一小串荔枝——三四颗红艳艳带着疙瘩外壳的荔枝挂在细枝上。她兴冲冲摘下一颗，捏住壳用力一挤，壳"啵"地裂开，露出晶莹半透的乳白果肉，汁水在壳内晃动。她捏着果肉送进嘴里，眼睛瞬间满足地眯起。吃上瘾后又摘一颗，这次挤得太用力，果肉"啵"地弹了出去，她急忙双手去接、没接住，果肉在画幅内弹跳了两下落地，她俯身追、指尖够不着，只好委屈地蹲着看。最后把掉落的果肉捡起来吹一吹吃掉，心满意足地把荔枝枝与果壳凭空消散，恢复标准正面站立。全程原地站立，双脚锚定原点，荔枝、果壳、果肉均在画幅安全区内。

**按秒分割画面**

0~2秒（变出荔枝串）：
标准正面站立。双手从身前以魔术般的动作，由半透明虚影渐次凝出一小串荔枝，红艳疙瘩外壳，连着细枝和两片小叶，三四颗一串，托在左手掌心，右手去摘。她低头看着荔枝，眼睛亮起，嘴角上扬。
⚠️ 强调：荔枝外壳要有明显瘤状疙瘩质感（不能画成光滑红球）；小叶与细枝保留，增加辨识度；整串大小不超过两个头宽。

2~4秒（挤壳 → 第一颗）：
她摘下一颗，用两只手指捏住，对着镜头方向用力一挤——"啵"一声，外壳从中间裂开一道缝，露出晶莹半透明的乳白果肉，果肉上还挂着一层亮亮的汁水。她把果肉捏出来送进嘴里，眼睛瞬间眯成弯月，腮帮子轻轻鼓了一下，尾巴愉快地摆了两下。
⚠️ 强调：挤壳动作要有明确的"捏 → 裂 → 掰"三个层次；果肉必须晶莹半透、能看到汁水反光，与其他食物的实心质感区分开。

4~6.5秒（第二颗 → 弹飞）：
她兴冲冲地又摘一颗，这次太急，用尽全力一挤——"啵！"果肉从壳里直接弹射出去，向上飞出画幅中部后呈弧线落下。她"啊"地张嘴，双手在身前慌忙去接，没接住，果肉在身前的空气中弹跳了两下落到地面位置，滚了半圈停住。她保持着双手前伸的姿势僵住，眼睛瞪圆。
⚠️ 强调：这是全片主笑点——弹射轨迹要清晰完整（射出 → 抛物弧 → 弹跳两下 → 停住），全程在画幅内、距边缘 ≥10%；接的动作是双手前伸，**身体不得向前移动或平移**。

6.5~8.5秒（俯身追 → 够不着）：
她急忙弯下腰用指尖去够那颗果肉，弯到一半发现够不着，只好整个上身再往下俯一点，屁股微微翘起，尾巴跟着抬起来，指尖在离果肉还有一小段距离的地方划了两下空气。她瘪起嘴，眉头皱成八字，发出委屈的"唔——"的表情。
⚠️ 强调：核心是"够不着"的滑稽；俯身是上身动作，**双脚必须留在原位不挪动**；尾巴因俯身自然抬起，属轴心动作，不算违反居中。

8.5~10秒（捡起吹吹吃掉 → 消散）：
她索性再俯低一点，终于用指尖捏到果肉，捡起来在嘴边"呼"地吹了两下（仿佛在吹灰），眼睛弯起来，把果肉塞进嘴里，满足地咀嚼、眯眼、点头。空荔枝枝与散落的红壳在胸前拢起，由实到虚化为光点淡去。双手自然垂落，身体直立，目光平视前方，嘴角带着"捡回来的更甜"的得意。第10秒结束时彻底恢复为标准正面站立。

**动作结束后状态**

最终帧：与参考图最左侧标准正面站立完全一致——双脚并拢，双手自然垂于身体两侧，目光平视前方，表情平和，呆毛柔顺，鲸鱼尾巴自然下垂。无荔枝、无荔枝枝、无果壳、无果肉、无光点残留。
```

## 啃甘蔗-嚼完吐渣

**动作概述**

Q版蓝发鲸尾女仆原地站立，双手以魔法手势由虚到实凝出一段甘蔗——紫黑透红、带白霜、有明显竹节，比她手臂还长。她双手握住两端，先试着用膝盖顶一下掰断，掰不动；又歪头张嘴去啃一口，牙齿咬得"咯嘣"响，费了九牛二虎之力才撕下一小片。她鼓起腮帮子用力嚼，嚼得脸颊一鼓一鼓，表情从"好费劲"慢慢变成"好甜"。嚼完发现嘴里有渣，左右张望一下，鼓起腮帮子把渣吐到一边，一脸"这也太麻烦了吧"的无奈，但又忍不住啃第二口。最后嚼完把渣吐掉、甘蔗段与渣凭空消散，恢复标准正面站立。全程原地站立，双脚锚定原点，甘蔗、蔗渣均在画幅安全区内。

**按秒分割画面**

0~2秒（变出甘蔗）：
标准正面站立。双手从身前以魔术般的动作，由半透明虚影渐次凝出一段甘蔗，紫黑透红、表面带一层薄白霜、三四个明显竹节，横着托在双手掌心，长度约等于她肩宽的两倍。她低头看着甘蔗，眉毛一挑，露出"这东西要怎么吃"的困惑。
⚠️ 强调：甘蔗必须有**明显竹节与白霜**这两个识别特征，紫黑偏红色调；横握姿势要稳，甘蔗两端不超出画幅两侧安全区。

2~4秒（掰不断 → 啃下来）：
她先双手握住甘蔗两端，试着往膝盖上一顶想折断——甘蔗纹丝不动，她用力到脸憋红、呆毛都在抖。放弃后，她歪头张大嘴咬住甘蔗一端，"咯嘣"一声用力扯头，费了很大力气才撕下一小片，脑袋随着撕扯被带得往后仰了一下。
⚠️ 强调：核心是"比想象的难啃"；膝盖顶的动作幅度小，**不得屈膝下蹲导致身体位移**；撕扯时后仰是上身动作，双脚不动；"咯嘣"咬合要有明显的用力感。

4~6.5秒（发狠大口啃）：
她瞪起眼睛，把甘蔗换到侧面（原地转身半圈，双脚不移动），双手抱住，张大嘴"咔嚓"就是一口，腮帮子立刻鼓得圆圆的，眼睛瞪大。接着像啃玉米一样沿着甘蔗一小口一小口连续啃下来，脑袋随着啃的动作一下一下前点，尾巴在身后有节奏地左右甩动。
⚠️ 强调：这是全片的"豪迈"段落，节奏要快、有韵律；转身是**原地轴心转**，允许上身与头转向侧面，但**双脚必须留在原位**；腮帮子持续饱满。

6.5~8.5秒（用力嚼 → 表情反转）：
她停下来，双手捧着甘蔗，腮帮子开始一鼓一鼓地用力咀嚼，脸颊被撑得圆鼓鼓，眼睛半眯。嚼了四五下之后，表情慢慢从"好费劲"软化为"嗯…好甜"，眉毛舒展，眼角弯起，露出惊喜。又嚼了两下，忽然意识到什么，咀嚼速度慢下来，眉头皱起。
⚠️ 强调：核心是"从嫌弃到真甜"的表情渐变，必须能看出是渐变不是突变；咀嚼节奏由快到慢是后段的关键信号。

8.5~10秒（吐渣 → 消散）：
她左右张望一下（只转头），鼓起腮帮子，"呸"地把蔗渣吐到身前一侧，露出一脸"好麻烦"的无奈表情，扁着嘴摇了摇头。随即手上吃剩的甘蔗段与地上的蔗渣由实到虚化为光点淡去。双手自然垂落，身体转回正面，目光平视前方，嘴角带着"麻烦但还想吃"的纠结笑意。第10秒结束时彻底恢复为标准正面站立。

**动作结束后状态**

最终帧：与参考图最左侧标准正面站立完全一致——双脚并拢，双手自然垂于身体两侧，目光平视前方，表情平和，呆毛柔顺，鲸鱼尾巴自然下垂。无甘蔗、无蔗渣、无白霜、无光点残留，脸颊恢复正常不鼓。
```

> **与已有动作的区分点**：进食机制是「先啃后吐渣」，全系列独有——这是唯一一个**吃的过程会产生废弃物**的动作。`ext_bigsnack`、`ext_dumpling` 等都是"吃下去就完了"；本条的"嚼完还得吐"正是笑点所在。

## 吃菠萝-扎手又挑不完的眼

**动作概述**

Q版蓝发鲸尾女仆原地站立，双手以魔法手势由虚到实凝出一只整只菠萝——金黄带绿冠、表面是菱形格纹、格子里嵌着一颗颗黑褐色"眼"。她伸手就要去抱，指尖刚碰到就被扎得缩回来，含住手指委屈地吹了吹。她只好改用一个小姿势：双手虚虚地捧着两端，用魔法手势让菠萝表面"削"开一层，露出金黄色果肉，可果肉上还嵌着一排排顽固的菠萝眼。她拿起小刀（魔法凝结的小刀）一颗一颗地挖眼，挖到一半手一滑，刀掉了；她索性张嘴直接对着挖好的一块咬下去，"咔嚓"一口，汁水丰沛、酸甜到皱起眉头又忍不住再咬。最后把小刀、菠萝皮、菠萝眼凭空消散，恢复标准正面站立。全程原地站立，双脚锚定原点，菠萝、小刀、果皮、果汁均在画幅安全区内。

**按秒分割画面**

0~2秒（变出菠萝 → 扎手）：
标准正面站立。双手从身前以魔术般的动作，由半透明虚影渐次凝出一整只菠萝：金黄带绿冠、表面菱形格纹、格子里嵌黑褐色"眼"。她眼睛一亮伸手去抱，指尖刚碰到就"嘶"地缩回来，把食指含进嘴里，眉头皱成八字，委屈地吹了两下手指。
⚠️ 强调：菠萝要一眼看出"扎手"——表面菱形刺点要清晰；缩手与含手指的反应要快、要真；菠萝整体高度控制在画幅高度约 30% 以内，避免触发"大物件"重排。

2~4秒（虚捧两端 + 魔法削皮）：
她学乖了，改用双手虚虚地托住菠萝上下两端，闭起眼睛认真施法。菠萝表皮沿着一道螺旋线被"削"开、卷成一长条果皮垂落，露出金黄饱满的果肉——但果肉表面仍留着一排排黑褐色的菠萝眼，深浅不一。她睁开眼，表情从开心变成"诶？还有这么多？"的无奈。
⚠️ 强调：削皮要用**螺旋连续剥落**的方式（果皮不断开），比"一刀切"更有观赏性；菠萝眼必须清晰保留在果肉上，这是后续"挑不完"的前提；果皮垂落但不得超出画幅底边。

4~6.5秒（一颗颗挖眼 → 手滑掉刀）：
她右手"啪"地凝出一把小刀，左手扶住菠萝，低头凑近，一颗一颗地沿着菠萝眼斜切挖除，动作细致、眉头紧锁、舌头不自觉地伸出一点。挖到第五六颗的时候，手上忽然一滑，小刀"叮"地脱手落到身前地面，她整个人一愣，保持着悬空的手势。
⚠️ 强调：挖眼动作要有明确的"斜切 → 剔除"节奏；掉刀是喜剧点，落刀要干脆、声音感要足；**刀落地后角色不得弯腰去捡导致位移**，只需低头看。

6.5~8.5秒（气到直接咬 → 酸到皱眉）：
她盯着地上那把刀，又看了看菠萝上还剩的一大半菠萝眼，叹了口气，干脆不挖了，双手捧起菠萝，张大嘴对着已经挖干净的一角"咔嚓"就是一大口。她眼睛先亮，随后立刻皱起整张脸——酸得眯眼、鼻子皱起、肩膀微微一缩，头还抖了一下。但紧接着她回味过来，眼睛又弯起，忍不住又咬了第二小口。
⚠️ 强调：这是本条的情绪核心——**"酸到皱眉"与"真香再咬"必须连着演**，形成反差；酸的表情要夸张可爱、不能显得厌恶；第二口幅度要明显小于第一口。

8.5~10秒（消散 + 恢复正姿）：
她满足地嚼完，用手背抹了一下嘴角，把剩下的菠萝、地上的小刀、卷起来的果皮在身前拢起，以魔术般的动作由实到虚化为光点淡去，指尖残留的果汁也随之消失。双手自然垂落，头部摆正，目光平视前方，嘴角带着"酸得够味"的回味。第10秒结束时彻底恢复为标准正面站立。

**动作结束后状态**

最终帧：与参考图最左侧标准正面站立完全一致——双脚并拢，双手自然垂于身体两侧，目光平视前方，表情平和，呆毛柔顺，鲸鱼尾巴自然下垂。无菠萝、无绿冠、无果皮、无菠萝眼、无小刀、无果汁、无光点残留。
```

刚把脸凑近，她整个人"呃！"地一下向后仰——头猛地缩回，鼻子皱成一团，舌头吐出来一点，一只手在脸前拼命扇风，另一只手把榴莲往旁边推了推。她偏过头去，一脸"这是什么"的嫌弃，尾巴嫌弃地甩了一下。
⚠️ 强调：这是全片前半的核心笑点——**闻到瞬间的后仰幅度要大、要快**，但**双脚绝不能移动**，后仰只靠上身与脖颈完成；扇风的手势要清晰；嫌弃必须可爱不要真恶心（不要出现呕吐或绿色气体）。

4~6.5秒（偷瞄 → 犹豫 → 捏鼻下口）：
她偏着头，眼睛却偷偷瞟回来，又闻了一下，皱眉，再瞟一眼，终于忍不住伸手掰下一小块淡黄果肉。她先用一只手捏住自己的鼻子，另一只手把果肉送到嘴边，闭着眼睛、表情像在做什么重大决定，张嘴吃了下去。
⚠️ 强调：核心是"嘴上嫌弃身体诚实"的犹豫过程——**偷瞄要来回两次**（这是制造喜剧节奏的关键）；捏鼻子是标志性动作，必须清晰可辨。

6.5~8.5秒（震惊 → 真香爆发）：
咀嚼第一下，她整个人瞬间僵住，眼睛猛地瞪圆，捏着鼻子的手也松开了。第二下、第三下，她的眉眼迅速舒展开来，脸颊浮起红晕，眼睛弯成月牙，嘴巴不由自主地加快咀嚼，尾巴兴奋地左右大甩。她"哇"地看向手里的榴莲，表情写满"怎么会这么好吃！"，随即毫不犹豫地又挖了一大块塞进嘴里，腮帮子鼓得圆圆的。
⚠️ 强调：这是全片的高潮反转点——**"僵住 → 舒展 → 加速 → 扑上去"四段递进**必须在 2 秒内演完；表情从震惊到迷醉的转变是核心，要夸张；尾巴的兴奋甩动是重要情绪外化。

8.5~10秒（满足 → 消散）：
她幸福地眯起眼睛，慢慢嚼完，满足地呼出一口气，拍拍肚子，还回味地舔了舔嘴唇。剩下的榴莲壳、几颗果核与残余果肉在胸前拢起，由实到虚化为光点淡去。双手自然垂落，头部摆正，目光平视前方，嘴角带着"我真有品位"的小骄傲。第10秒结束时彻底恢复为标准正面站立。

**动作结束后状态**

最终帧：与参考图最左侧标准正面站立完全一致——双脚并拢，双手自然垂于身体两侧，目光平视前方，表情平和，呆毛柔顺，鲸鱼尾巴自然下垂。无榴莲、无榴莲壳、无果肉、无果核、无光点残留，脸颊红晕褪去。
```

> **与已有动作的区分点**：进食机制是「气味反转」，全系列独有——这是唯一一个**笑点不在嘴里而在鼻子里**的动作。`ext_rice`、`ext_bigsnack` 等全部是"看到 → 想吃 → 吃"的直线情绪；本条的曲线是"期待 → 嫌弃 → 犹豫 → 震惊 → 真香"，是全系列最长的一段情绪反转。
