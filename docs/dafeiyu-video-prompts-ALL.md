## 一、实测经验与写作规范

| 现象 | 原因 | 解法 |
|---|---|---|
| 首帧变黑背景 | 用白底参考图 | 改用**绿底**参考图 |
| 角色被推成特写 | 动作写「凑近/靠近/仰头猛喝」 | 禁止此类词；给具体百分比 |
| 道具怼满画面 | 只说"大小不变"太抽象 | **给数值**：宽33% 高74% 面积17% |
| 道具掉落 | 未约束归属 | 加「**道具绝不脱手**」整段 |
| 吃进嘴没演出来 | 约束挤占动作篇幅 | 见下方「篇幅配比铁律」 |

### 工具硬限制：prompt 上限 2500 字符

超出会直接报错。文档里 3500 字符的完整条目需压缩后使用。

### 篇幅配比铁律

> **动作描述必须占 prompt 总篇幅的 50% 以上。**
>
> 推荐分配：约束 ~1200 字（48%）+ **动作 ~1300 字（52%）**

### 「入口」动作必须写全

进食类必须包含完整链条：

```
拿起/剥开 → 举到嘴边 → 张开嘴 → 放入口中 → 合上嘴 → 咀嚼（腮帮起伏）→ 咽下 → 满足
```

禁止写法：“再把一瓣送进嘴里” / “然后吃了下去”

```markdown
> **本片必须是远景全身镜头**，角色全身从头到脚完整可见，画面上下留有大量空白，角色只占画面高度的 74%，**绝不拍摄半身或特写**。

## 通用前缀

> **【绝对空间与边界约束强制命令】**  
> 视频比例 16:9，背景必须为纯粹的绿幕色（标准 Chroma Key Green，颜色严格统一为 #00FF00），无任何阴影、杂物、渐变或边框，背景本身即为单一纯色块。
> **人物位置与大小强制固定**：人物必须完完全全处于画面正中心偏下位置。人物头顶始终处于画面垂直方向约 20% 的位置，脚底始终处于画面垂直方向约 85% 的位置，最左和最右边缘始终处于画面水平方向约 25% 和 75% 的位置。不同视频之间的人物大小、位置、比例必须完全一致，不允许有任何偏差。
> **人物周围缓冲区（防裁切）**：人物头顶距离画幅顶边至少保留 15% 画幅高度的绿色空间，脚底距离画幅底边至少保留 10% 画幅高度的绿色空间，身体左右两侧距离画幅边缘至少保留 10% 画幅宽度的绿色空间。
> **【画幅安全红线（统一数值，全程强制）】**：全库安全缓冲统一为 **画幅任意一边的 10%**。动作全程任何一帧，角色**任何身体部位**（顶部的呆毛、耳侧的鳍饰、底部的裙摆与鲸鱼尾巴、手脚与指尖）以及**所有道具与特效对象**，在最高点/最外点都必须与画幅对应边缘保持 **≥10% 画幅宽/高** 的安全间距；**绝对禁止**任何部位或对象接触、触碰、超出或被裁剪（剪切）。动作全程必须在画幅内部完成。
> **【绝对居中锚点（强制）】**：人物双脚落点坐标恒定为屏幕正中央，全程 **不允许产生 X 轴或 Y 轴平移位移**（仅允许轴心旋转、原地跳跃、脚尖原地点地）。**无论出现多大体积的道具或场景对象，角色与对象的组合视觉重心必须始终保持在画面水平正中**；严禁为了容纳道具或对象而把角色整体向左右移动、向后移动或靠向画幅边缘。
> **【大物件构图规则（强制）】**：出现较大体积物件（如圣诞树、木马、烟花、雪人、孔明灯等，高度＞画幅 30% 时）——① 物件必须位于**角色正前方 / 正上方 / 环绕角色轴线**，并与角色共用画面水平中心线，禁止放成“身侧/一侧偏左偏右”导致画面重心偏移；② 若物件受画幅所限放不下，**宁可把物件 Q 版缩小以整体入画并保持在安全区内**，**绝不**移动人物来腾空间；③ 角色与物件必须同框，人物始终占据画面中心主干位置，双脚与原点静止。
> **【“无→有→无”道具闭环（强制）】**：所有含道具/特效/交互对象的视频，**入场第一帧必须是与参考图完全一致的标准正面站立、画面干净——无任何道具、无任何特效、无任何对象**（仅纯绿幕背景 + 角色本体）；道具与对象一律由角色以魔法手势 **从无到有、由虚到实地渐进凝聚生成**（先出现半透明虚影轮廓，约 0.5~1 秒后凝实为实体），**绝不直接出现在起始帧**；并在动作结束前 **从有到无、由实到虚地渐次消散**（约 0.5~1 秒化为光点淡去），使画面回到无任何道具的标准正面站立。任何一帧都不得凭空直接出现未经生成过程的道具，最终帧不得残留任何道具或特效。
> **【侧身互动 ≠ 构图横移（强制）】**：需要侧身/转身面向物件的互动，一律指角色**原地轴心**转动上身、头部或脚尖原地点地转向来面向物件，**双脚与画面中心原点始终保持静止、不横移、不后移、不靠边**；凡“退后、后退、后移、走到一侧、挪到旁边、偏右/偏左站位”等会造成整体位移的描述一律视为违规，应改写为原地轴转或原地重心微调。
> 所有视频 **必须以参考图最左侧的标准正面图为第一起始帧（此帧画面干净、无任何道具或特效），并在视频最后一秒（第 10 秒结束时）彻底恢复到与第一帧完全一致、无道具残留的标准正面站立姿态**。  
> **不同视频之间的绿色背景色值必须完全一致，不允许有色差。**

## 吃烤红薯-烫嘴哈气

**动作概述**

Q版蓝发鲸尾女仆原地站立，双手以魔法手势由虚到实凝出一只烤红薯和一只牛皮纸袋——红薯个头比她的脸还大一圈，表皮焦褐起皱，顶端裂开一道口子，冒着细细的白气，香气冲天。她捧起红薯，被烫得左右手来回倒腾、呼呼吹气，好不容易掰开，露出金黄流蜜的瓤，热气"腾"地冒上来糊了她一脸。她迫不及待咬下一大口，结果烫得舌头一缩、张嘴哈气、眼角泛泪，拎着红薯原地轻轻跺脚。缓过来后小口小口地吹着吃，最后满足地眯起眼，把牛皮纸袋和红薯皮一起凭空消散，恢复标准正面站立。全程原地站立，双脚锚定原点，红薯、纸袋、白气均在画幅安全区内。

**按秒分割画面**

0~2秒（变出红薯）：
标准正面站立。双手从身前以魔术般的动作，由半透明虚影渐次凝出一只烤红薯和一只牛皮纸袋。红薯焦褐表皮起皱、顶端裂口，冒出细白热气；纸袋敞口朝上，托在左手掌心。她双手捧起红薯，刚碰到就"哎哟"一下缩手，眉头一挑。
⚠️ 强调：红薯要明显"烫"——热气持续细微冒出；红薯表皮质感粗糙、有焦痕，不要画成光滑土豆；纸袋口朝上不遮挡脸。

2~4秒（烫手倒腾 → 掰开）：
女仆被烫得把红薯在左右手之间快速来回倒腾三次，每次都"呼、呼"地吹手指，眼睛瞪圆、嘴巴嘟起。随后她把红薯往中间一掰——"啪"地裂成两半，金黄流蜜的瓤露出来，一大团白气"腾"地升起，正好扑在她脸上，她眯起眼睛、鼻子皱起、被香气冲得表情发懵。
⚠️ 强调：掰开的动作要清晰，白气是向上"腾"起的一大团，但不得遮挡面部超过 0.5 秒；红薯断面要有金黄流心质感。

4~6.5秒（烫到哈气 → 跺脚）：
她迫不及待咬下一大口，刚入口表情就僵住——两眼猛地睁大，眼角泛起泪花，嘴巴"呼哈呼哈"地张着哈气，一只手在嘴边来回扇风，舌头微微伸出。随后她拎着红薯原地轻轻跺脚两下（脚尖原地点地，双脚不移动），尾巴紧张地卷起来。
⚠️ 强调：这是全片主笑点，核心是"贪吃被烫到"的委屈可爱，不是痛苦；跺脚必须是原地脚尖点地，**禁止身体前后左右平移**；舌头外伸幅度小而可爱。

6.5~8.5秒（吹着吃 → 满足）：
缓过来后，她学乖了，捧起红薯对着断面一下一下地吹气，眼睛半眯。然后小口小口地咬，腮帮子一点点鼓起来，每咬一口都眯眼点头，尾巴在身后慢慢左右摆动。吃到一半忽然想起什么，加快速度大口咬。
⚠️ 强调：吹气动作要有节奏感（三口），与前面的"狼狈"形成对比；表情从委屈转为享受。

8.5~10秒（消散 + 恢复正姿）：
女仆把最后一口咽下，满足地呼出一口白气，拍拍肚子。手握红薯皮与牛皮纸袋在胸前拢起，以魔术般的动作由实到虚消散（约0.5秒化为光点淡去），残余热气缓缓隐去。双手自然垂落，头部摆正，目光平视前方，嘴角带一丝被烫过又吃撑了的浅笑。第10秒结束时彻底恢复为标准正面站立。

**动作结束后状态**

最终帧：与参考图最左侧标准正面站立完全一致——双脚并拢，双手自然垂于身体两侧，目光平视前方，表情平和，呆毛柔顺，鲸鱼尾巴自然下垂。无红薯、无红薯皮、无牛皮纸袋、无白气、无光点残留。
```

```markdown
Q版蓝发鲸尾女仆原地站立，双手以魔法手势由虚到实凝出一块方形牛奶巧克力——表面有整齐的方格纹，包着半剥开的锡纸。她开心地拈起巧克力，却不急着吃，捏在指尖上举到眼前一点一点端详。天太热，巧克力开始在她指间慢慢变软、塌角、融化，一滴褐色顺着她的手指往下淌。她慌了，赶紧舔了一下手指，结果越舔越糊，整只手掌都变成褐色。她看着自己黏糊糊的手，表情从惊慌变成"算了就这样吧"，索性把剩下软塌塌的巧克力整块塞进嘴里，满足地眯眼。最后把锡纸与手上的巧克力渍凭空消散，恢复标准正面站立。全程原地站立，双脚锚定原点，巧克力、锡纸、融化物均在画幅安全区内。

⚠️ 强调：巧克力必须有**清晰的方格纹**与**半剥的锡纸**两个识别特征；锡纸要有金属反光质感，与巧克力哑光表面形成对比。

2~4秒（拈起端详 → 开始融化）：

⚠️ 强调：核心是"慢慢塌"的融化感，必须是渐进过程而非瞬间变形；融化从她捏住的指尖处开始，这是关键细节。
```

```markdown
⚠️ 强调：打嗝时身体向上一弹，但**弹起也不得离地走动**；打完要有一秒的僵住。
```

```markdown
## 吃生日蛋糕-吹蜡烛抹一脸奶油

**动作概述**

Q版蓝发鲸尾女仆原地站立，双手以魔法手势由虚到实凝出一只小巧的圆形生日蛋糕，白色奶油抹面、边缘挤着波浪花边，顶上插着三根点燃的小蜡烛，还缀着几颗红草莓。她先被烛光吸引，双手合十闭眼许愿，然后鼓起腮帮子"呼"地把蜡烛吹灭，蜡烛上冒出细细一缕白烟。她拿起小刀切下一块，用叉子送进嘴里，眼睛立刻眯成月牙。吃第二口时太急，鼻尖蹭到奶油，她愣了一下，用手背一抹——结果奶油在脸上抹开一大片，越抹越大，最后索性把脸上的奶油也舔了。蛋糕与蜡烛凭空消散，恢复标准正面站立。

**按秒分割画面**

0~2秒（变出蛋糕 → 烛光）：
标准正面站立。双手从身前以魔术般的动作，由半透明虚影渐次凝出一只小巧的圆形生日蛋糕：白色奶油抹面、边缘波浪花边、顶上三根点燃的小蜡烛、缀着三颗红草莓。烛光微微摇曳。她双手捧蛋糕，眼睛被烛光映得发亮。

⚠️ 强调：蛋糕是**小巧圆形**，白色奶油抹面 + 波浪花边 + 三根点燃蜡烛 + 红草莓；整体高度控制在画幅约 25%，避免触发大物件重排。

2~4秒（许愿 → 吹蜡烛）：
她把蛋糕举到胸前，闭上眼、双手合十，表情认真而温柔，嘴角带笑——安静地许愿约 1.5 秒。然后睁开眼，深吸一口气鼓起腮帮子，"呼——"地把三根蜡烛一齐吹灭，烛火灭的瞬间冒出三缕细白烟缓缓上升。她开心地笑起来。

⚠️ 强调：许愿段要安静：闭眼、双手合十，**不能有位移**，时长约 1.5 秒不能省；吹灭后必须看到**三缕细白烟上升并散去**。

4~7秒（切一块 → 满足）：
她右手凝出一把小刀和一把叉子，小心地在蛋糕上切下一块（切口整齐、能看见里面的蛋糕胚与奶油夹层），用叉子送到嘴边"啊呜"吃下，腮帮子鼓起，眼睛眯成月牙，头轻轻晃了两下。尾巴愉快地摆动。

⚠️ 强调：切开要能看见**蛋糕胚与奶油夹层**，切口整齐；吃下时腮帮子鼓起到位。

7~10秒（第二口 → 鼻尖蹭奶油）：
她迫不及待地又叉了一大块，这次吃得太急，鼻尖"啪"地蹭到奶油，留下一个小白点。她动作停住，眼珠往下看自己的鼻子，露出一副"糟糕"的表情。

⚠️ 强调：鼻尖蹭奶油是**一个小白点**，不要大面积糊脸；停住看鼻子的“糟糕”表情要清楚。

10~12秒（手背抹 → 越抹越大）：
她腾出一只手，用手背在鼻子下面抹了一下——结果奶油没抹掉，反而在脸颊上摊开成一大片。她又抹了第二下，范围更大了。她停住，把两只手摊在眼前看了看，一脸无奈又好笑。

⚠️ 强调：手背抹是第一层失误：奶油被**摊开成一大片**而不是抹掉，这是“越抹越大”的笑点所在；只用手背，不加手指涂抹。

12~14秒（舔掉 → 消散）：
她眼睛转了转，索性凑近手指舔了一口脸上的奶油，发现很好吃，眼睛亮起来，把手指上剩下的也舔干净，还满足地眯了眯眼。剩下的蛋糕、蜡烛、小刀叉在胸前拢起，由实到虚化为光点淡去，烛烟缓缓散开。双手自然垂落，头部摆正，目光平视前方。第14秒结束时彻底恢复为标准正面站立。
```

```markdown
> **【“无→有→无”道具闭环（强制）】**：所有含道具/特效/交互对象的视频，**入场第一帧必须是与参考图完全一致的标准正面站立、画面干净——无任何道具、无任何特效、无任何对象**（仅纯绿幕背景 + 角色本体）；道具与对象一律由角色以魔法手势 **从无到有、由虚到实地渐进凝聚生成**（先出现半透明虚影轮廓，约 0.5~1 秒后凝实为实体），**绝不直接出现在起始帧**；并在动作结束前 **从有到无、由实到虚地渐次消散**（约 0.5~1 秒化为光点淡去），使画面回到无任何道具的标准正面站立。任何一帧都不得凭空直接出现未经生成过程的道具，最终帧不得残留任何道具或特效。
> **【侧身互动 ≠ 构图横移（强制）】**：需要侧身/转身面向物件的互动，一律指角色**原地轴心**转动上身、头部或脚尖原地点地转向来面向物件，**双脚与画面中心原点始终保持静止、不横移、不后移、不靠边**；凡“退后、后退、后移、走到一侧、挪到旁边、偏右/偏左站位”等会造成整体位移的描述一律视为违规，应改写为原地轴转或原地重心微调。
> 所有视频 **必须以参考图最左侧的标准正面图为第一起始帧（此帧画面干净、无任何道具或特效），并在视频最后一秒（第 18 秒结束时）彻底恢复到与第一帧完全一致、无道具残留的标准正面站立姿态**。  
> **不同视频之间的绿色背景色值必须完全一致，不允许有色差。**

## 涮火锅-丰盛版（多轮涮煮）

**动作概述**

Q版蓝发鲸尾女仆原地站立，双手以魔法手势由虚到实凝出一只小巧的鸳鸯锅（一边红汤翻滚、一边清汤微沸），锅沿冒着腾腾热气，周围环绕着几小碟食材：肥牛卷、土豆片、青菜、丸子，还有一小碗蘸料。她先惊喜地看看这一桌，然后筷子不断：先涮一片肥牛，七上八下，捞起来蘸料吃下，满足地眯眼；再涮土豆片，等得有点急；接着夹起一颗丸子，一咬被烫得直哈气；最后捞青菜时抢到一片"漏网"的，开心地举高。全程热气升腾、汤面微动。最后锅与菜碟凭空消散，恢复标准正面站立。

**按秒分割画面**

0~2.5秒（变出鸳鸯锅与食材）：
标准正面站立。双手从身前以魔术般的动作，由半透明虚影渐次凝出一只小巧的鸳鸯锅——左半边红汤翻滚冒泡、右半边清汤微沸，锅沿升起腾腾白气。锅的四周悬浮着几小碟食材：肥牛卷（红色带白纹）、土豆片、青菜、丸子，还有一小碗蘸料。她惊喜地瞪大眼睛，嘴巴微张，双手在胸前拍了一下。

⚠️ 强调：鸳鸯锅需左边红汤翻滚、右边清汤微沸，锅沿白气持续；锅整体高度不超过画幅约 35%，四周食材碟**环绕锅轴**、共用水平中心线，不得挤到两侧。

2.5~6秒（涮肥牛 → 蘸料 → 吃）：
她右手凝出长筷，夹起一片肥牛卷放进红汤里，熟练地"七上八下"涮了几下（筷子在锅中上下移动），肉片由红变褐。捞出来在蘸料里蘸一下，送进嘴里——腮帮子鼓起，眼睛眯成月牙，头满足地晃了一下，尾巴大幅摆动。

⚠️ 强调：“七上八下”的涮肉动作要清晰可读，肉片由红转褐是必现细节；蘸料后才吃。

6~9.5秒（涮土豆 → 等急了）：
她把土豆片放进清汤里，双手撑着锅边等着，眼睛盯着锅里一动不动，闲得另一只手在锅边轻轻敲了两下。等了几秒忍不住夹起来看了看（还硬），又放回去，皱了皱鼻子，露出等不及的委屈表情。

⚠️ 强调：等土豆时的**盯锅不动**是节奏需要，不要加多余动作；夹起查看又放回的动作要小。

9.5~13秒（夹丸子 → 一咬烫到）：
她夹起一颗圆润的丸子，看着很诱人，迫不及待咬下去——"嘶！"丸子里面滚烫，她立刻张嘴哈气，眼睛瞪大、眉毛皱起，一只手在嘴边扇风，还轻轻在原地跺了一下脚（脚尖点地，身体不移动），尾巴紧张地卷起。

⚠️ 强调：丸子烫嘴是笑点：张嘴哈气、眼角泛泪；**跺脚必须是脚尖原地点地，身体不得位移**。

13~15.5秒（抢到青菜 → 开心）：
缓过来后她继续涮，最后在锅里捞到一片"漏网"的青菜，夹起来举高看了一眼，露出抢到宝的得意笑容，咔嚓吃掉。

⚠️ 强调：抢到青菜的得意表情要明显，举高但**不超出画幅上缘 10% 安全线**。

15.5~18秒（满足 → 消散）：
她放下筷子，双手撑着锅边满足地"哈"出一口气，拍拍肚子，还把最后一口汤舀起来喝了。鸳鸯锅、食材碟、筷子、蘸料碗一起由实到虚化为光点淡去，热气缓缓散开。双手自然垂落，头部摆正，目光平视前方，嘴角带着吃撑的满足。第18秒结束时彻底恢复为标准正面站立。

⚠️ 强调：喝汤时碗要倾斜但**不遮脸、不超画幅**；最后热气要缓慢散尽。

**动作结束后状态**

最终帧：与参考图最左侧标准正面站立完全一致——双脚并拢，双手自然垂于身体两侧，目光平视前方，表情平和，呆毛柔顺，鲸鱼尾巴自然下垂。无鸳鸯锅、无食材碟、无筷子、无蘸料碗、无热气、无汤汁、无光点残留。
```
