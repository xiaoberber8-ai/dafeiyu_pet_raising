# 大肥鱼 · 大餐类提示词（5 道，上游资产库没有的）

> 角色：`characterId: "whaletail-maid"`（蓝发 + 鲸鱼尾巴 + 呆毛）
> 首帧参考图：`ref/ref_standing_green_640x360.png`（绿底版）
> 用途：补充上游 106 个动作里**没有**的大餐类型
> 更新：2026-11-20

---

## 一、为什么补这 5 道

上游资产库（`PC2005-cloud/dsh-pet`）现有的大餐只有：

| 已有 | clip |
|---|---|
| 火锅 | `ext_hotpot` |
| 大闸蟹 | `ext_crab` |
| 饺子 | `ext_dumpling` |
| 午餐 / 晚餐 | `ext_lunch` / `ext_dinner` |
| 大口零食 | `ext_bigsnack` |

**完全没有的常见大餐**：烧烤、披萨、汉堡、炸鸡、寿司、拉面、牛排、小龙虾、烤鸭、麻辣烫、串串、生煎……

本次挑出 **5 道** 最有辨识度、且动作机制互不重复的：

| # | 菜 | 机制 | 为什么选它 |
|---|---|---|---|
| 1 | 烧烤 | 撸串 | 中式夜宵代表，动作独特（顺签子撸） |
| 2 | 披萨 | 拉丝 | 西式快餐代表，芝士拉丝有画面感 |
| 3 | 汉堡 | 太大咬不下 | 分量梗，纯表情戏 |
| 4 | 牛排 | 切不动 | 刀叉用餐礼仪，与手抓类形成对比 |
| 5 | 小龙虾 | 剥壳+嗦指 | 中式夏夜代表，动手+狼狈感 |

```markdown
【镜头规格·第一优先级】
本片是远景全身镜头：角色全身从头到脚完整可见，只占画面高度74%，四周绿幕大量留白。绝不拍摄半身或特写。

【动作：吃烧烤-撸串撸到嘴】

0~2秒（变出烤串）：标准正面站立，双脚并拢，双手垂在身侧。接着双手在身前抬起，由半透明虚影凝聚出三串烤肉串——竹签上串着焦褐带亮油光的肉块，表面撒着白色芝麻和红色辣椒粉，还冒着细细的烟。她双手捏着竹签下端，低头看着这三串，眼睛一下亮了，嘴角上扬。

2~3.5秒（举到嘴边→撸第一串）：她右手把其中一串举到嘴边，头微微后仰，张大嘴，咬住最顶端的那块肉，然后头一偏顺着竹签往下一撸——肉块被整块撸进嘴里，合上嘴，签子上空了一截。腮帮子鼓起来，眼睛满足地眯成月牙。

3.5~5秒（咀嚼→辣到）：她嚼了两下，脸上突然一红——辣到了。眉毛挑起、眼睛睁大、鼻尖冒出一点汗，张开嘴哈了两口气，还甩了甩筷子上的空签子，尾巴也跟着抖了一下。

5~6.5秒（撸第二串→越来越快）：她甩甩头，又举起第二串，这次撸得更快，一口撸下两块，腮帮子鼓得满满的，眼睛又满足地眯起来。手里的空签子仍在左手捏着，没扔。

6.5~8秒（撸第三串→吃到嘴油）：她举起最后一串，又是一撸到底，三根空签子都攥在左手里。她的嘴角沾了一层油光，脸颊微微发亮，还抬起手背擦了擦嘴。

8~10秒（满足→消散）：她把三根空签子在手里晃了晃，满足地"哈——"呼出一口气，拍拍肚子，露出吃撑了的表情。手里的空签子和嘴边油光由实到虚化为光点淡去。双手自然垂落，头部摆正。第10秒结束时彻底恢复为标准正面站立。

末帧：与参考图完全一致的标准正面站立，双脚并拢，双手自然垂于身体两侧，目光平视前方，表情平和，呆毛柔顺，鲸鱼尾巴自然下垂。无烤串、无竹签、无油光、无烟、无光点残留。
```
