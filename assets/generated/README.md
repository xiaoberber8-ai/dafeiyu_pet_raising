## 后续处理

这些是**原始绿幕视频**，还需走完素材链才能进插件：

```powershell
# 1. 抠像（若 WorkBuddy 输出已带 alpha 则跳过）
ffmpeg -y -i ext_water_raw_8s.mp4 -vf "chromakey=0x00FF00:0.20:0.06,format=yuva420p" `
  -c:v libvpx-vp9 -pix_fmt yuva420p -crf 30 -b:v 0 -an ext_water.webm

# 2. 转 WebP 帧序列
python ../tools/webm_to_frames.py ext_water.webm out/ext_water --clip ext_water

# 3. 注册到插件
python ../tools/register_clip.py --clip ext_water --frames <实际帧数> --idle
```

详见 `docs/dafeiyu-workflow.md`。
