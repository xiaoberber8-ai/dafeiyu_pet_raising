## 测量方法说明（重要）

早期用「非绿色像素包围盒」测角色尺寸，会被三类干扰误导：

| 干扰 | 表现 | 实际 |
|---|---|---|
| 漂浮特效（白气/光点） | 宽度虚高 | 角色正常 |
| 掉落的道具 | 宽度虚高 | 角色正常 |
| **背景渐变** | **判定为 100% 占画** | **角色正常** |

**正确做法**：用**最大连通域**测量角色本体。
烤红薯正是因此从「87% 失败」纠正为「31~34% 合格」。

## 经验教训

1. **必须用绿底参考图** —— 白底会导致首帧变黑
2. **禁止"凑近/靠近"类词** —— 会诱导镜头推近
3. **精细操作（剥皮/掰瓣）极易诱发特写** —— 橘子在 WorkBuddy 上反复失败 5 次
4. **"从大件取下部件"会导致整个件被丢下** —— 榴莲壳掉落的原因
5. **大团热气/白气会变成漂浮白球** —— 需限定为"一小缕"
6. **代理会切断图片轮询** —— WorkBuddy 生成时必须关闭系统代理
7. **prompt 上限 2500 字符** —— 文档里 3500 字符的完整版发不出去
8. **Trae 的角色尺寸稳定性优于 WorkBuddy** —— 波动 0.3% vs 3~5%

## 后续处理

```powershell
# 1. 抠像
ffmpeg -y -i ext_coffee_raw_10s.mp4 -vf "chromakey=0x00FF00:0.20:0.06,format=yuva420p" `
  -c:v libvpx-vp9 -pix_fmt yuva420p -crf 30 -b:v 0 -an ext_coffee.webm

# 2. 转 WebP 帧序列
python ../tools/webm_to_frames.py ext_coffee.webm out/ext_coffee --clip ext_coffee

# 3. 注册到插件
python ../tools/register_clip.py --clip ext_coffee --frames <实际帧数> --idle
```
